# Звуки персонажей

Необязательно. Звук проигрывается при выпадении персонажа, если включён звук (кнопка 🔊 под кнопкой выбора) — **только на вкладке «Персонажи»**.

**Имя файла = имя персонажа**, расширение: `.mp3 .ogg .wav .m4a`.

Пример: `Эмбер.mp3`. Список имён — в `../images/README.md` (те же имена, только звуковое расширение).
