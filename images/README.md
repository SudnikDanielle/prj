# Картинки персонажей

Картинка показывается при выпадении персонажа **только на вкладке «Персонажи»**.

**Имя файла = имя персонажа**, расширение любое из: `.png .jpg .jpeg .webp .gif`.

Пример: `Эмбер.png`, `Ху Тао.jpg`.

Если картинки нет — она просто не показывается, ошибок не будет.
